# YM UNCENSORED

Неофициальный клиент Яндекс Музыки для macOS, Windows, Linux и Android. Плеер ищет подходящую версию песни в каталоге и подключённых внешних источниках, сохраняя место исходного трека в очереди, обложку и лайк. Личные загрузки не участвуют.

В версии 0.2.2 подключите «Внешние источники» при первом запуске или в настройках плеера. Подтвердите отдельный вход через Яндекс ID и вернитесь в приложение. После локальной проверки звука плеер запоминает подтверждённую замену. Без подключения можно слушать исходные каталожные треки.

Пакеты для Mac имеют локальную подпись ad hoc. Доступность каталожных треков зависит от аккаунта и подписки.
