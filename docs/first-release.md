# YM UNCENSORED

Неофициальный клиент Яндекс Музыки для macOS, Windows, Linux и Android. Плеер может автоматически выбрать личную загрузку для песни из каталога, сохранив её место в очереди, обложку и лайк.

Создайте в Яндекс Музыке приватный плейлист с точным названием **YM UNCENSORED** и загрузите в него свои оригиналы. У каждого файла впишите обычное название песни и исполнителей через запятую. При следующем входе клиент прочитает плейлист и будет подставлять только однозначные совпадения по названию, исполнителям и длительности.

Пакеты для Mac имеют локальную подпись ad hoc. Для загрузки каталога и личных записей нужен вход в Яндекс ID. Доступность каталожных треков зависит от аккаунта и подписки.
