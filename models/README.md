# Модели определения языка

Многоязычная модель Whisper tiny в формате GGML Q5_1 используется только локально. SHA-256 файла `ggml-tiny-q5_1.bin` равен `818710568da3ca15689e31a743197b520007872ff9576237bda97bd1b469c3d7`. Лицензия находится в `WHISPER-LICENSE`. [Исходная модель](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-tiny-q5_1.bin)

Для проверки восстановленных слов официальные сборки также включают многоязычную модель Whisper small Q5_1 размером 190 085 487 байт. Сборщик сверяет SHA-256 `ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb`. Распознавание выполняется на устройстве. [Исходная модель](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-small-q5_1.bin)

Файл `ru-headwords.zlib` получен из русского орфографического словаря Александра Лебедева. Для названий песен оставлены словарные формы из трёх и более русских букв, приведённые к нижнему регистру, без флагов Hunspell. При подготовке исключены слова, которые также встречаются в украинском, белорусском, болгарском и сербском словарях LibreOffice. Условия распространения приведены в `RUSSIAN-DICTIONARY-LICENSE`. [Исходные словари](https://github.com/LibreOffice/dictionaries)
