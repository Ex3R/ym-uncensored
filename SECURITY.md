# Безопасность

Исправления выходят только для последней версии. Обновлялка ставит её сама, так что старые версии
отдельно не чинятся.

## Как сообщить

Не открывайте публичный issue. Напишите через
[Security → Report a vulnerability](https://github.com/Ex3R/ym-uncensored/security/advisories/new):
такой отчёт видят только владельцы репозитория, и в нём же идёт обсуждение.

Опишите, что происходит, как это повторить и в какой версии. Если для проверки понадобился ваш
токен или лог, не прикладывайте их целиком, хватит фрагмента без токена.

## Что считается уязвимостью

- Токен Яндекса отправляется куда-то кроме `yandex.ru` и `yandex.net`, не по https или попадает
  в лог.
- Токен может прочитать другая учётная запись Windows или программа, которой не нужен доступ
  к DPAPI текущего пользователя.
- Обновлялка ставит файл, который не совпадает с `yamusic-rs.exe` из релиза, или скачивает его
  не с GitHub.
- Ответ сервера или файл из кэша может заставить приложение выполнить чужой код.

Ошибки в API Яндекса, падения и расхождения с официальным приложением — это обычные баги, о них
пишите в [issues](https://github.com/Ex3R/ym-uncensored/issues).

## In English

Please report security issues privately via
[Report a vulnerability](https://github.com/Ex3R/ym-uncensored/security/advisories/new), not in
public issues. Only the latest release gets fixes.
