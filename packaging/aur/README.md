# Установка YM UNCENSORED на Arch Linux

Готовый пакет AUR для форка пока не публикуется. Используйте [AppImage с сайта проекта](https://ym.idkroma.ru/#download) или [публичные релизы форка](https://github.com/Ex3R/ym-uncensored/releases).

[Архивный PKGBUILD yamusic-rs 1.1.2](../../docs/upstream-aur-v1.1.2.PKGBUILD) сохранён для истории происхождения. Он устанавливает исходный проект SpolzerMod/yamusic-rs, а не YM UNCENSORED. Его исходные адреса, авторство и контрольная сумма сохранены.
